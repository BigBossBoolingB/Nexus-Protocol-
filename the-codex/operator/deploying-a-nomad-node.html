Chapter 1: Deploying a Nomad Node

This guide provides a complete, step-by-step process for installing a Nomad Node on a compatible Linux system (e.g., Ubuntu, Debian, CentOS) using the Sovereign Deployment Kit (The Forge).

Prerequisites:

  • A machine running a supported Linux distribution.
  • A stable internet connection.
  • sudo or root privileges for system-wide installation.

Step 1: Acquire The Forge SDK

First, you must acquire the architect's primary tool. Open your terminal and download the latest version of The Forge SDK from the official repository.

# Download the binary
wget https://your-repository.com/forge-nexus/latest/forge-nexus-amd64

# Download the checksum for verification
wget https://your-repository.com/forge-nexus/latest/forge-nexus-amd64.sha256

Step 2: Verify the Tool's Integrity

A sovereign trusts nothing unverified. Before proceeding, perform a cryptographic check to ensure the SDK has not been tampered with. This is a non-negotiable step.

# Verify the checksum
sha256sum -c forge-nexus-amd64.sha256

You should see an OK confirmation. If the check fails, do not proceed. Delete the files and report the issue.

Step 3: Prepare The Forge

Once verified, make the SDK executable and move it to a system-wide path for easy access.

# Make the binary executable
chmod +x forge-nexus-amd64

# Move it to your local bin
sudo mv forge-nexus-amd64 /usr/local/bin/forge-nexus

You can now invoke the SDK from any location by simply typing forge-nexus.

Step 4: Install the Nomad Node

With The Forge prepared, you can now command it to build your post. This single command will automatically detect your operating system, download the correct nexus-node binary, verify its integrity, and install it on your system.

sudo forge-nexus install --role=nomad

The SDK will handle all dependencies and place the nexus-node binary in /usr/local/bin/. It will also create the necessary configuration directories and install a systemd service file.

Step 5: Configure Your Post

A generic post must be given a specific mission briefing. Run the interactive configuration command to customize your node.

sudo forge-nexus configure

This will guide you through setting a public alias for your node, adjusting resource limits, and other key settings.

Step 6: Assume the Watch

Your node is now installed and configured. The final step is to bring it online and assume your watch as a guardian of the network.

# Start the service
sudo forge-nexus start

# Check the status to ensure it is running correctly
sudo forge-nexus status

Congratulations, Architect. Your Nomad Node is now a live, sovereign participant in the Nexus Protocol.
